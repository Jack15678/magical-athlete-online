# 小地图、连锁节奏与绊倒规则核对

更新：2026-10-21。

## 对局表现

小地图由桌面190px／手机110px放大到252px／148px。自己的棋子使用金色大环，位置卡显示头像、角色名和“你 · 第N格”；两人双角色用A/B对应地图与头像。其他选手单独标明选手号和格数。同格点位按网格分散并连回实际位置，自己的标记最后绘制，避免被其他标记盖住。

技能提示默认1.1秒。长队列只对尚未开始的片段温和调整速度，技能仍至少0.9秒、移动至少0.7秒；不再把任意长度的连锁挤进9秒或11秒。移动时继续显示“技能／箭头格 → 前进／后退N格”，提示和结果衔接。减少动效保留文字阅读时间；用户明确选择2×、4×或跳过时仍按其选择处理。新快照不能改变已经开始播放的片段计时。

这只改变表现时钟，没有修改规则引擎、AI选择、随机结果或服务器裁定。需要自己选择时仍优先同步已确认局面并展示选项。

## 绊倒核对

依据[发行商FAQ v2.0](https://iello.fr/athletes-de-compete-tatillon-repond-a-vos-questions/)和[官方规则书](https://iello.fr/wp-content/uploads/2026/02/Magical-Athlete_Rulebook_FR_Light.pdf)印刷p14/p21，区分“主移动”和技能带来的其他效果。常规情况详见[规则规格中的绊倒表](rules.md#绊倒后的技能掷骰与移动2026-10-21补充核验)。

- 绊倒不关闭能力。回合开始、持续、被动能力仍按自身条件生效。
- 本应开始主动作时已经倒地，则以起身替代；不掷主骰、不走主移动。大长腿和人字拖不能绕过恢复；没有主骰也就没有相应预测、炼金或重掷窗口。
- 决斗这类独立技能骰仍可掷；胜者照常移动，技能骰不当作主骰。
- 技能、其他角色和特殊格仍可带动或传送倒地棋子；这种移动不自动解除倒地。
- 回合开始技能使本人倒地且主动作尚未开始时，本回合就以起身替代。野兔独自领先会跳过主动作，倒地也不能借跳过恢复。

一个需要明确区分的窗口是“已投主骰、骰面技能连锁中才倒地”：现有官方文字没有直接回答该精确组合。网页保留当前已开始动作，倒地留待下一次本可执行主移动时恢复；这是现行网页推导裁定，不声称是官方特例。具体自然组合、文本依据与边界见[研究缺口第6项](research-gaps.md)。本次没有修改引擎语义。

菜单“帮助与规则”已同步提供中文说明，网页房规也公开该未决边界。

## 验证

`pnpm typecheck`、两种生产构建及Worker部署预演通过。`pnpm test`共209项通过，其中新增的绊倒专项为14项通则和1项明确标注的网页裁定；表现层覆盖可读时间下限、反复快照不重复压缩、当前计时不重启、减动效及显式加速、选择优先和跳过。

浏览器实测共8项通过、0页面脚本错误：

- 两项小地图／因果专项（15秒）：桌面252px、390和320px手机148px，双向无滚动，视角按钮、状态和镜头设置不遮地图；双角色A/B、8人同格、移动中格数与因果横幅均通过。两次技能实测1104／1106毫秒，完整链跟拍后正常回位。
- 六项原有回归（1.3分钟）：电脑跟拍回位、总览、手动暂停、手机选择优先、确认骰面后移动、重连不重播、同时交换后绊倒、传送、后退、跳过及设置均通过。

手机结论是Windows Edge的390×844和320×667视口模拟，不代表实测了所有手机硬件。实际截图：[桌面小地图](qa/minimap-desktop.png)、[手机小地图](qa/minimap-mobile.png)、[技能移动原因](qa/skill-move-reason.png)。上线结果记录于[测试汇总](testing.md)及[部署记录](deployment.json)。
