# 网页房规（独立于官方规则）

- 7–8人显示“7–8人扩展规则”。沿用每人4张唯一角色、四场、每场1名Racer；两批各2N张蛇形选秀，第二批起选者左移一座。奖分不调整。未验证与官方2–6人同等平衡。
- Egg只从未分配牌堆抽3张，候选不得从他人手牌或已用卡获得。8人选32张后仍留4张，首次Egg可抽3。候选记录为本场复制参考，不成为手牌；赛前复制连锁再次需要抽牌而不足3张时，从仍可用未分配候选重新洗牌补足，绝不复制他人初始手牌；具体可用集和补牌日志公开。这是网页牌堆不足补充裁定。
- 本场选择的数组顺序就是同一玩家多个Racer的固定顺序。选秀和首场先手骰由服务器生成并记录。
- 可配置操作超时默认90秒。可选技能超时选择“不使用”；必选目标取合法列表首项；骰面预测选1；选秀取展示第一张；暗选取自己剩余卡序的前1/2张。自动策略会记录在事件日志，所有默认选择仍通过同一合法动作验证。
- 长时掉线保留席位、重连凭据和分数，超时按以上规则继续。房主离线不暂停服务器，管理权可转给在线玩家。邀请链接不能用于冒充原玩家。
- 在已核验文本仍有真实冲突而官方桌游允许掷骰解决时，网页用服务器记录的掷骰决定；不会由网络先后到达选择优先级。具体未确认裁定必须在研究缺口中列明，不能把本规则页当成官方勘误。
- 执行预算用于分批处理事件。遇到不能自动证明的循环暂停诊断并保留队列；不会因为技能触发次数多就结束比赛。
