# 网页房规（独立于官方规则）

- 自己练习为单人教学模式：开局从完整102张角色牌池（原作36、Second Wind 36、Wurstii A类30）自由选择4张不同角色牌；旧基础版本存档保持36张，Second Wind版本旧存档保持72张。四场每场独自出场1名，自己冲线即结束当场。确认前可以查看、取消和重选；服务端一次校验完整阵容后才建立手牌。无其他活跃选手时，野兔仍正常进行主移动，避免独自领先规则使练习无法继续；此项仅适用于自己练习，人机和好友对局保留野兔正式规则。依赖其他选手的技能没有合法目标时照常不发动或选择不使用。
- Wurstii A类是用户提供PDF中的角色适配，采用当前30格赛道、四场赛制和玩家积分。可选择“原作＋Wurstii A”66张或“全部混合”102张牌池；原两代混合仍为72张。A类不是官方兼容或平衡性认证；完整中文名、卡文、复制与禁能等边界见 [Wurstii A类规则](../public/rules/wurstii-a.md)。
- 旧版练习存档若还在首轮两批选秀中途，确认自由四张阵容会原子替换尚未完成的旧手牌，并把未选角色归还候选牌堆，保留既有随机记录；已进入暗选或比赛的旧练习不重置。
- 人机对战可加入1～7名AI，使用对应人数的同一选秀、暗选、技能、随机和计分裁定。AI只读取公开赛道、已揭示角色、公开日志以及自己的手牌和当前合法选择，无法读取牌堆顺序、其他玩家手牌或未来骰子；行为与操作超时策略分别处理。AI在相邻操作间稍作停留，单场结算由真人房主点击下一场。
- 回合开始事件由系统自动推进，包括起身、跳过主移动和掷骰前技能选择；完成需要玩家决定的选项后，掷骰按钮才用于掷骰。
- 绊倒的骰后边界：主移动骰已经投出后，若骰面触发的技能连锁使行动者倒地，本网页继续完整处理当前已开始的主动作，保留已结算的骰面与技能，并保留倒地状态，待下一次本可执行主移动时起身；明确取消或替换主移动的技能仍按自身规则处理。此项是网页现行推导裁定，尚无发行商针对该组合的明确特例答复，不能称为官方勘误；详细依据记录在项目的研究缺口中。主动作开始前已经倒地，则仍按通则在本回合起身而不掷主移动骰。

- 7–8人显示“7–8人扩展规则”。沿用每人4张唯一角色、四场、每场1名Racer；两批各2N张蛇形选秀，第二批起选者左移一座。奖分不调整。未验证与官方2–6人同等平衡。
- Egg只从未分配牌堆抽3张，候选不得从他人手牌或已用卡获得。8人选32张后仍留4张，首次Egg可抽3。候选记录为本场复制参考，不成为手牌；赛前复制连锁再次需要抽牌而不足3张时，从仍可用未分配候选重新洗牌补足，绝不复制他人初始手牌；具体可用集和补牌日志公开。这是网页牌堆不足补充裁定。
- 双人赛每场确认两名选手时同时确认先后；本场选择的数组顺序就是同一玩家多个Racer的固定顺序。统一计算端保存并公开本场基础行动顺序，完整结算一名选手的掷骰、移动、技能及后果后才推进下一名，不预掷两颗骰子后分配。下场重新选择；明确改变次序或追加行动的技能仍优先按技能处理。选秀和首场先手骰由本局统一计算端生成并记录。
- **自定义双人规则：粘液怪（Gunk / Slime）的主移动−1效果排除同一玩家控制的全部选手，仅影响对方符合条件的选手。** 原版“其他选手”只排除技能持有者自身，包含其队友；这项改动是本项目产品选择，不是官方修订。仅限此效果，催眠师、尺蠖等技能的“其他选手”仍按各自规则判断；多人模式保持粘液怪原规则。
- 决斗的两名参与选手分别由自己的控制玩家点击投掷，真人控制的第一、第二名选手待遇一致。首颗骰面保存在私有续接状态，两人均投掷后一起揭晓；刷新、重连和重复请求均保留同一待操作步骤。真人决斗投掷不由超时策略代掷，AI继续自动操作。
- 当前新规则下，真人的所有待处理技能选择（包括强制目标、回合外猜测、继续掷骰和决斗）都等待当前控制者，不由AI或超时流程代选；刷新与重连保留待选步骤。选秀、暗选与主移动掷骰仍使用房间配置的时限。旧规则存档的超时行为保持原状。
- 旧规则存档可配置操作超时默认120秒，也可在建房时选择不限时。可选技能超时选择“不使用”；重掷窗口保持原骰面；其他必选目标取合法列表首项；骰面预测选1；选秀取展示第一张；暗选取自己剩余卡序的前1/2张；主移动超时代掷骰；单场结算超时进入下一场。真人的必选决斗投掷始终等待点击，不设代掷期限。大厅不会自动准备或开局，终局不会自动再来一局。自动策略会记录在事件日志，所有默认选择仍通过同一合法动作验证。
- 长时掉线保留席位、重连凭据和分数。重连凭据保存在原浏览器；刷新、短暂断线后可恢复，清理浏览器数据会失去凭据，昵称相同不代表同一身份。邀请链接与房间号只授予加入能力，请勿分享本机身份凭据。主方案由创建者的网页统一计算，该页面应保持打开；计算房主离线时全房暂停，回到创建房间的原浏览器后从本地存档继续。清理站点数据可能丢失对局；手机切后台或设备休眠也可能暂停计算。房主管理权可转交，但计算页面和秘密存档仍属于创建者，其他玩家不能凭邀请接管。备用本机方案由运行游戏程序的电脑保存进度；关闭玩家页面不停止该程序，关闭程序或电脑后无法联机，重新启动可从存档恢复。以上超时策略仅在本局计算端在线时执行。
- 在已核验文本仍有真实冲突而官方桌游允许掷骰解决时，网页用本局统一记录的掷骰决定；不会由网络先后到达选择优先级。具体未确认裁定必须在研究缺口中列明，不能把本规则页当成官方勘误。
- 执行预算用于分批处理事件。遇到不能自动证明的循环暂停诊断并保留队列；不会因为技能触发次数多就结束比赛。
