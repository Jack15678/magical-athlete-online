# 网页房规（独立于官方规则）

- 自己练习为单人教学模式：开局按房间角色包设置自由选择4张不同角色牌；开启全部已完成包时为121个来源区分卡牌条目。没有新包设置的旧练习存档保留原72张，更早的基础规则存档保持36张，四场每场独自出场1名，自己冲线即结束当场。确认前可以查看、取消和重选；服务端一次校验完整阵容后才建立手牌。无其他活跃选手时，野兔仍正常进行主移动，避免独自领先规则使练习无法继续；此项仅适用于自己练习，人机和好友对局保留野兔正式规则。依赖其他选手的技能没有合法目标时照常不发动或选择不使用。
- 旧版练习存档若还在首轮两批选秀中途，确认自由四张阵容会原子替换尚未完成的旧手牌，并把未选角色归还候选牌堆，保留既有随机记录；已进入暗选或比赛的旧练习不重置。
- 人机对战可加入1～7名AI，使用对应人数的同一选秀、暗选、技能、随机和计分裁定。AI只读取公开赛道、已揭示角色、公开日志以及自己的手牌和当前合法选择，无法读取牌堆顺序、其他玩家手牌或未来骰子；行为与操作超时策略分别处理。AI在相邻操作间稍作停留，单场结算由真人房主点击下一场。
- 回合开始事件由系统自动推进，包括起身、跳过主移动和掷骰前技能选择；完成需要玩家决定的选项后，掷骰按钮才用于掷骰。
- 绊倒的骰后边界：主移动骰已经投出后，若骰面触发的技能连锁使行动者倒地，本网页继续完整处理当前已开始的主动作，保留已结算的骰面与技能，并保留倒地状态，待下一次本可执行主移动时起身；明确取消或替换主移动的技能仍按自身规则处理。此项是网页现行推导裁定，尚无发行商针对该组合的明确特例答复，不能称为官方勘误；详细依据记录在项目的研究缺口中。主动作开始前已经倒地，则仍按通则在本回合起身而不掷主移动骰。

- 7–8人显示“7–8人扩展规则”。沿用每人4张唯一角色、四场、每场1名Racer；两批各2N张蛇形选秀，第二批起选者左移一座。奖分不调整。未验证与官方2–6人同等平衡。
- **当前v3复制抽牌裁定（2026-10-22修订）**：Egg、Mush、Thespian、Filmmaker共用真实未选牌堆；不足时只洗公共弃牌，不从启用角色全集重新造牌。正式手牌、已用角色、当前展示牌、私人影片手牌及选秀区都不能重复抽取。Egg最多取得实际可得的3张候选，0张则公开说明本次无新能力；完成选择后整组候选回公共弃牌，能力引用不占用一张额外实体牌。本条替代此前“不足3张从未分配候选全集补足”的网页房规；更早v1/v2冻结引擎不变。
- **临时抽牌嵌套**：同一选手在同一回合内，每种主骰前抽牌/选牌机制最多执行一次。临时取得另一种机制时，当前主骰前窗口仍可处理其尚未执行的一次指令，但不补发赛前私人手牌；取得自己或已执行过的同种机制不再抽牌。同文能力不叠加，所有临时子层统一在自身下回合开始失效，永久额外能力独立保留。展示卡在同一来源实际换新牌时归公共弃牌；未再换牌的旧展示在赛末归还，它本身不代表能力仍有效。完整示例、历史冠军及资源裁定见[复制能力相互作用](copy-ability-rulings.md)。
- 双人赛每场确认两名选手时同时确认先后；本场选择的数组顺序就是同一玩家多个Racer的固定顺序。统一计算端保存并公开本场基础行动顺序，完整结算一名选手的掷骰、移动、技能及后果后才推进下一名，不预掷两颗骰子后分配。下场重新选择；明确改变次序或追加行动的技能仍优先按技能处理。选秀和首场先手骰由本局统一计算端生成并记录。
- **自定义双人规则：粘液怪（Gunk / Slime）的主移动−1效果排除同一玩家控制的全部选手，仅影响对方符合条件的选手。** 原版“其他选手”只排除技能持有者自身，包含其队友；这项改动是本项目产品选择，不是官方修订。仅限此效果，催眠师、尺蠖等技能的“其他选手”仍按各自规则判断；多人模式保持粘液怪原规则。
- 决斗的两名参与选手分别由自己的控制玩家点击投掷，真人控制的第一、第二名选手待遇一致。首颗骰面保存在私有续接状态，两人均投掷后一起揭晓；刷新、重连和重复请求均保留同一待操作步骤。真人决斗投掷不由超时策略代掷，AI继续自动操作。
- **当前v3超时裁定**：技能选择先等待对应控制者；系统即时推进及AI调度不能消费真人操作。房间配置有时限时，只有真正到达保存的截止时间后，普通技能选择按“不使用/保留原骰/允许技能/首个合法选项”的次序取默认动作；技能范围骰、送礼骰等单选投掷到期后也可明确记录为超时代操作。所有代操作通过同一合法动作接口，并先向全员记录实际操作人的超时说明。选择不限时则一直等待，刷新重连不重扣次数。**Duelist决斗骰与Cletus对抗骰双方真人均保持手点保护，不设超时代掷**；AI控制的该选手仍可正常操作。旧v1/v2房间保持各自冻结规则和原超时行为。
- 房间可配置操作超时默认120秒，也可在建房时选择不限时。可选技能超时选择“不使用”；重掷窗口保持原骰面；其他必选目标取合法列表首项；骰面预测选1；选秀取展示第一张；暗选取自己剩余卡序的前1/2张；主移动超时代掷骰；单场结算超时进入下一场。真人的必选决斗及Cletus对抗投掷始终等待点击，不设代掷期限。大厅不会自动准备或开局，终局不会自动再来一局。自动策略会记录在事件日志，所有默认选择仍通过同一合法动作验证。
- 长时掉线保留席位、重连凭据和分数。重连凭据保存在原浏览器；刷新、短暂断线后可恢复，清理浏览器数据会失去凭据，昵称相同不代表同一身份。邀请链接与房间号只授予加入能力，请勿分享本机身份凭据。新建网页房间由服务器的 SQLite Durable Object 统一结算和保存完整秘密状态，网页不提交骰子结果，关闭房主网页不会丢失服务端已确认状态。升级前的旧浏览器计算房间沿用原路径：计算网页应保持打开，离线时暂停，返回原浏览器后从 IndexedDB 继续；清理其站点数据可能丢失旧对局。显式转交房主改变管理权限和离线保留期限归属，刷新和退出不自动移交。备用本机方案由运行游戏程序的电脑保存进度；关闭玩家页面不停止该程序，关闭程序或电脑后无法联机，重新启动可从存档恢复。以上超时策略仅在本局计算端在线时执行。
- 在已核验文本仍有真实冲突而官方桌游允许掷骰解决时，网页用本局统一记录的掷骰决定；不会由网络先后到达选择优先级。具体未确认裁定必须在研究缺口中列明，不能把本规则页当成官方勘误。
- **当前v3循环与执行预算**：只有完整规则相关状态与相同嵌套后续分支重现时，才保留已完成的一遍并在下一遍之前停止该循环分支，其他合法后续继续。积分、生命、控制权、能力和资源持续变化的合法链继续结算；随机恰巧相同及玩家再次选相同选项不当作确定循环。每次最多3000事件后让出并恢复，4005事件跨调用已验证完成。异常连续9000事件独立诊断暂停本房间，保留种子、状态、日志及未执行队列，不吞事件、不改骰、不补判赢家。跨回合无法分离的强制重复分支在v3同样暂停保留状态，**不再将本场改判和局**。
- **历史v2专用裁决（当前v3不采用）**，2026-10-22曾授权：若完整规则状态重复且期间没有会改变结果的随机、放弃或改选目标等出口，确认跨回合强制循环，则本场按和局收尾。保留已经取得的名次和积分，未完赛者不补判名次、不追加名次分或收尾奖励；正常继续下一场。仅重复相同选择但仍有其他合法出口时，不强行裁决真人比赛。此规则由用户授权，不宣称官方续作裁定。
- 骰子先生六颗主骰均不相同时，公开本组结果后等待当前控制者点击重掷整组六骰；主移动尚未执行，不消耗额外回合。重掷仍按一般骰子规则处理。v2保持真人不代投，v3仅在配置的操作期限真正到达时可公开记录超时代投，AI即时调度不能替真人操作。这是2026-10-22新增项目房规，不改变官方资料待核验状态；旧v1存档维持旧行为。
