# 复制、抽牌与多能力相互作用裁定

核查日期：2026-10-22。适用于当前 `cmyk-base-aug2026-fan-v3` 网页规则；旧 v1/v2 引擎仍保留各自规则。本页将来源直接支持的规则与本项目为跨包联机作出的裁定分开。Second Wind 仍是转录核验状态，粉丝扩展也不因此成为官方扩展。

## 先区分身份、能力与资源

角色身份和棋子不随复制改变；当前控制者负责该选手的选择、投掷及私人手牌。一个选手可以同时拥有主要能力、赛末到期的额外能力，以及下回合到期的借用能力。“拥有”与“正在生效”也有区别：Null 可以使所拥有能力暂时不生效。

**项目裁定**：同一选手同时从多个来源取得同一种能力，按一种卡文生效；不同选手实例各自触发。例如 Mush 永久获得 Coach 后，再临时借 Coach，不会为自己创造两份 Coach；临时借用结束也不会删除永久 Coach。两个不同选手各有 Coach，则仍是两个来源。

能力文字可以复制，目标实例、已掷骰、次数余额、生命、私人手牌、已经建立的坐骑和标记不会跟着复制。它们属于原选手或已经建立的对象。复制者使用自己的资源、控制者与之后的合法操作窗口。

兼容边界：新版在冠军冲线时保存该场的主要能力快照。旧 v3 存档如果已经被后场同身份状态覆盖，无法逆推出丢失的冠军能力；恢复时只使用仍保存的历史字段，不补造来源或结果。冻结的旧规则版本继续使用原规则引擎，不套用本轮新增的复制裁定。

## 嵌套与时点

1. **赛前链只在赛前继续。** Egg → Twin → 历史冠军能力，或 Understudy → Egg，可以接着处理新取得卡的赛前指令。对同一选手，同种赛前指令只初始化一次，防止再抽到 Egg 或互选 Understudy 无限重复。出现已经处理过的赛前文字时，保留当前能力及已完成结果，停止重复该指令；不重发积分、七张私手或对象。
2. **Copycat 的限制随能力来源走。** Egg、Mush、Doppel 或借牌取得 Copycat，仍不能用 Copycat 的当前目标补发赛前指令；不能用“身份不是 Copycat”绕过限制。它取得的其他独立能力不因此一并被取消。
3. **中场获得不倒带。** Mush、Doppel、Thespian、Filmmaker 或中场重洗得到 Sisyphus，不补四分；得到 Filmmaker 不补七张；得到 Mastermind 时，已经过去的自身首次回合开始不补预测。之后还未到达的被动计算或触发窗口照常生效。
4. **回合开始与主骰前分开。** Leaf 临时能力在自身下回合开始到期，即便本回合因为起身、野兔跳过而没有抽新牌，也不会继续持有过期能力。新借牌在主骰前取得，不能倒补本回合已经完成的回合开始能力。
5. **已有动作完成后再刷新。** Copycat 在一次移动开始时拥有的跟随、越过及移动后效果，不能因为这次移动改变领先者而被截掉；之后的新动作再按新领先者重算。选择窗口到来时仍要核验合法目标。
6. **赛前重洗遵守已经排好的初始化顺序。** Shuffler 发动后，不倒回已处理选手的赛前窗口；尚未轮到的选手按轮到时的主要能力初始化。中场重洗不会使全桌重新开赛前。这是保留现有调度顺序的项目裁定。
7. **淘汰不能当作已夺冠。** Doppel 将首冲线改成淘汰后，该选手没有取得冠军，不触发预测它获胜的 Mastermind。多个有效 Doppel 对这同一冲线各消耗本场一次，之后不会再次拦截；已被淘汰的接收者也不会因得到能力继续在赛生效。
8. **一次主移动只执行一种主动替代方式。** 同时得到 Legs、Flip Flop 等替代方法时，由当前控制者选择适用方式，不能把“代替主移动”串成多次主移动。不同被动加减仍按正常顺序作用于适用的同一次移动；固定距离并不凭空产生骰面。

以上是固定时点通则在本网页复制系统中的具体落实；跨包递归的停止方式及资源隔离属于项目裁定。

## 临时抽牌再得到临时抽牌能力

这里用 **T** 表示 Thespian，**F** 表示 Filmmaker，“→”表示当前主骰前取得下一种能力。例子讨论能力层；实际抽牌还必须满足真实牌区约束，不会为了组成示例生成重复实体卡。

作者 Rulebook 明确主骰前取得新卡能力、忽略赛前文字，并规定当前牌的展示与归还。它没有定义 T/F 互相复制。以下是**本轮项目防递归裁定**：每个选手实例、每个自身回合、每种抽牌机制最多执行一次；同文新增来源不刷新这次标记。当前主骰前新获得另一种尚未执行的机制，可以继续执行，但不能补它错过的赛前准备。整条临时链共同在下个自身回合开始到期，子层不能给父层续期。立即获得的额外回合也算下个自身回合，不等其他人轮完才到期。

| 当前链或组合 | 这一回合如何结算 | 下个自身回合开始 |
|---|---|---|
| T → T | 同一种机制本回合已抽过一次，不再抽；不把同名卡当作另一份抽牌次数。 | 本次借用到期，原本永久持有的 T 继续保留。 |
| T → F，没有既存影片私手 | F 的赛前抽七张不补发；没有影片可弃，因此这一分支不再抽牌。 | 临时 F 到期，不能因此凭空留下七张。 |
| T → F，仍有该实例先前合法建立的影片私手 | 若 F 本回合尚未执行，可以从自己的现存私手选一张，执行一次 F；不新补七张。 | T、F 借用产生的各临时槽一起到期，剩余私手仍按实际牌区保存。 |
| F → F | 已经用 F 弃出一张，不再弃第二张，不补充影片私手。 | 临时 F 到期，原有永久 F 保留。 |
| F → T → F | F 已弃一张；新得 T 可抽一次；再得到 F 不会让 F 再弃一次或重抽七张。 | 两个机制的临时层一起到期；永久 F 不受影响。 |
| F → T，再遇到已展示的同一张 T 实体牌 | 同一实体牌已经在 F 的展示槽，不能再次从牌堆抽出占另一个槽；恢复存档中的重复牌区条目会被排除，T 抽下一张真正可得牌。若只是又取得 T 卡文，也不重开 T 本回合已用机制。 | 按实际合法的两个借用来源到期，不复制实体牌。 |
| F → T → Banana 等普通卡 | F 所借 T 与 T 所借普通卡各有独立临时来源，在剩余合法窗口内都可生效；T 不倒补已过的回合开始效果。 | 两项借用一起到期，不把第二次借用当作更晚一回合。 |
| 原本同时有 T 与 F | T、F 按现有固定机制次序各执行一次；各有自己的当前展示牌和归还记录，不因一个共用“已借牌”标记吞掉另一个。 | 两个临时槽均到期；下一次主骰前才按仍拥有的机制重新处理。 |
| 永久有 Banana，临时链也借到 Banana | Banana 卡文按一份生效，永久来源与临时来源都记录。 | 只删除临时来源，永久 Banana 仍在。 |
| 临时链中途被 Null 压制，或下回合只起身 | 压制期间不能继续发动抽牌；不能靠不掷主骰延长已取得的借用。 | 到期照常发生；没有本回合主骰前窗口则不抽新牌。 |

**展示牌不等于仍拥有能力。** 借用到期后，旧牌仍是上一回合的展示记录，不能因这张牌尚未归还就列入当前拥有能力。按作者换牌规则，该来源下次弃新牌时旧牌才进入公共弃牌；若来源能力已失去、之后不会再换牌，则最迟在本场结束时统一回收。保留这张展示物不会延长能力期限，也不会暗中进入其他人的可抽牌堆。选择“下次同机制换牌或赛末归还”是对作者原文的统一项目落实，避免一层到期把另一层仍在使用的牌误还。

## 同名、禁用、失去与控制权

| 情况 | 本项目的明确处理 |
|---|---|
| 同名或同一人多个选手 | 按稳定选手实例判断，不用昵称或角色名混在一起。卡文“其他选手”可以含自己的另一名选手；“对方选手”要求当前控制者不同。两个包的 Nepo Baby 是不同卡 ID。 |
| 同能力来自多个渠道 | 能力去重，来源独立留存；临时层到期只移掉那个来源，不能删永久层或另一借用槽。 |
| 同时拥有 Thespian 与 Filmmaker | 两个独立临时槽，各在自己的主骰前窗口执行一次；各有展示牌、期限及弃牌归还。不能用一个共用“本回合已借牌”标记吞掉另一能力。 |
| 被 Null 禁用 | 所有主要、永久及临时能力停止生效；拥有记录、已经花过次数、资源与正常到期时间继续保留。离开压制范围恢复剩余状态，不重新初始化赛前奖励或补满次数。被禁用的 Null 不再压制前方。 |
| 复制被 Null 压制者 | 印刷文字复制依然取卡文，不复制压制状态；但复制者自己仍须独立检查 Null。Doppel 取“有效能力集合”，所以被压制目标没有可转移的有效能力。 |
| 获得 Fox / Kraken 等有限次数能力 | 每名选手用自己的本场次数。失去后重获不回满；复制来源的已用余额不转移，两个同文来源也不叠成双倍次数。 |
| 失去 Mastermind | 预测失效并清除；重获不恢复旧预测，不重开首次回合窗口。Null 暂时禁用、Fox 阻止单次效果不等于失去拥有权，不删预测。FAQ 对 Copycat 的确证规则作为这类能力失去的统一项目边界。 |
| 交换控制权 | 所有能力、期限、资源、展示牌和私人影片手牌随选手实例；由新控制者接手后续选择。前控制者下一份投影不再得到该私手。控制权改变不会刷新次数或取消已经确认的动作。 |
| 完赛或淘汰 | 能力停止参与在赛触发；已经取得的能力不会让原拥有者复活。已建立物件是否留存按物件规则处理，不能通过复制/洗牌把原坐骑、Gary 或标记复制搬走。 |

Fox 可以阻止一次尚未生效的能力，不把永久“拥有该能力”删掉；成功阻止的该次效果不产生新的复制、抽牌或补发。多个 Fox 按固定顺序响应，首个成功即关闭窗口；不对“阻止”再开互相阻止窗口。已经付出的费用或次数不返还。这些反对窗口和资源处理是现有数字适配，不是作者卡面的额外文字。

Re-Runner 沿用现有项目跨场边界：本场结束登记时仍有效拥有它，或本来就是 Re-Runner 身份的选手，会登记后续额外参赛；中途取得可以参加这次赛末检查，临时借用已到期则不能凭旧展示牌登记。已经建立的后续参赛条目不因之后失去能力而撤回。本轮没有把它改造成复制私人卡、继承原拥有者后续阵容的方式；续作这一跨场边界仍未获官方逐项复核。

## 未选牌堆、展示和秘密

**本轮修订的项目牌堆裁定**：Egg、Mush、Thespian、Filmmaker 从真实未选牌堆依序抽取；空时只洗真实公共弃牌。不再从“启用包全集减去阵容”重造候选。这样不会把他人影片私手、正在展示或已经被另一抽牌步骤取走的实体牌重新生成。

- Egg 实得至多三张。只有选中那张作为公开复制信息；未选候选不能因规则审计或头像详情泄露。选择结束后，候选按本项目既有处理进入公共弃牌，不成为阵容手牌。
- Mush 抽出的卡按本项目既有处理进入公共弃牌，得到的是到赛末的能力记录，不占一张新的阵容牌。之后同一张实体卡再次被抽到，也只产生一份同文能力。
- Filmmaker 的未弃私手留在该选手，不进入公共弃牌；其他人及观战者不能看到。当前展示牌不在可洗弃牌中；上一张展示牌到下次换牌才归还。
- 本场结束时，所有尚在私人影片手牌与展示区的实体牌统一归公共弃牌，供后场使用，不能随旧选手实例销毁而凭空消失。结果详情仍可保留这场结束时的能力记录。作者资料没有写明回收步骤，本网页作为牌区守恒裁定公开采用。
- 牌堆和可洗弃牌都空时，不虚构牌、不取他人手牌、不跨未启用角色包补牌。Egg 零张则记录无候选，不新增能力；Filmmaker 七张不够时只拿实际可得张数；其他抽牌同样只处理实得牌。
- 恢复存档时先排除未启用包及已被私人手牌、当前展示等占用的牌，保留合法牌相对顺序；复制延续任务执行时也重新校验启用包。

这修订了旧 `house-rules.md` 中 Egg 不足三张便从未分配全集重建的补牌方案。新裁定优先保证牌区一致和私人牌安全；不宣称桌游作者已发布同样的补牌勘误。

## 可对照的典型结果

| 局面 | 应见结果 |
|---|---|
| Egg → Copycat，领先者 Sisyphus | 显示当前模仿 Sisyphus；不给赛前四分。 |
| Copycat 模仿已选 Hare 的 Twin | 显示 Twin 印刷文字；不给 Hare 的 +2，也不重新选历史冠军。 |
| 第一场 Egg 以 Sisyphus 冠军，后面同身份再得亚军 | Twin 仍可复制第一次冠军当时的 Sisyphus；不会读取后面亚军状态。 |
| Mush 同时永久有 Coach、临时借 Coach | Coach 一份；下回合临时层到期后永久 Coach 仍在。 |
| 两个 Doppel 同时取得首位冲线者 | 两者从同一个淘汰前快照得到能力；接收先后不改变结果。 |
| 先借 Kraken 用过，再永久得到 Kraken | 保留该选手已用次数；不因换来源再次发动。 |
| 同时有 Thespian / Filmmaker，前者借 Legs、后者借 Banana | 两张当前展示及两项临时来源清楚可见，均到自身下回合开始到期；主移动替代按合法选择处理。 |
| 借用后下回合只起身 | 借用先到期；没有掷主骰窗口则不抽新牌，不延长旧能力。 |
| Null 压制拥有多项能力的 Mush | 拥有来源仍可查看，但全部标成禁用；离开后恢复原有剩余状态。 |
| Filmmaker 换控制者 | 新控制者可以选其剩余影片；其他人只见数量和已公开展示牌。 |

头像详情以当前生效能力为第一层，附来源、到期及禁用说明；原始身份和控制者信息作为补充。公开详情不能替代私有投影权限，也不能把身份卡面误报为当前实际拥有能力。
