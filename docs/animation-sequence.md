# 完整演出、决斗参与和冠军预测

更新：2026-10-21。

## 修复原因

此前为了优先展示自己的待选技能，`prioritizeLocalChoice` 会在下一回合待选项到达时直接重建表现基线，清空尚未播完的骰子、技能和移动。人机裁定通常比动画快，所以更容易触发；真人联机也共用这条路径。本次删除该隐式跳播，待选面板和选择镜头都等待已确认队列完成。

另外修复两条独立路径：普通页面播报只有最后120条，超长单次动作可能造成日志缺段；客户端现按接收游标向已认证的权威页面或Node服务分页补齐公开事件，每页控制在96KiB内，完整后才交给表现层。其他房主提前推进下一场时，本机保留旧棋盘和未播事件，播完后才显示新阵容。初次进入、真正重连和明确重新开始仍从当前局面建立基线，不重播历史比赛。

新片段与开始时间在同一次渲染绑定，连续骰子不再短暂继承上一骰的结束时钟或已揭晓状态。重复快照和后续AI操作只追加事件，不重启当前计时。规则本应同时发生的多个目标仍在同一片段内一起移动，其后反应按权威日志顺序播放。

## 节奏和交互

技能默认1.8秒，长队列、2×、4×及减少动效都保留至少1.5秒阅读时间。普通默认骰子完整播放2.5秒。只有用户明确点击跳过才直接对齐已确认结果；动画不改骰面、选项、移动或胜负。

决斗选定对象后，挑战方与应战方各点击一次“掷决斗骰”，AI自动完成自己的按钮响应。第一次的骰面只存在私有续算状态，保存和重连后也不重复投；双方完成后才公开成对骰面。同一持久3D骰盘同时展示两个头像、两枚骰子和两点数，默认3秒内先运动、后保留至少1.5秒静止读数，再依次显示胜负、技能和胜者移动。决斗的独立骰、平手归决斗家、胜者前进两格及倒地技能通则均保持原裁定。

幕后军师预测在对应确认演出完成后，持续显示预测者、归属选手和预测对象；普通移动、掷骰和后续技能不会移除提示。支持多名预测者及模仿猫，真实进入本场可从存档恢复；本场结束时隐藏。

四场人机实测还发现一个独立问题：复制随行能力的双胞胎会与蹭蹭怪在狂野赛道16格后退箭头间反复选择随行。首轮完整浏览器验收因此中止，不计为通过。AI现在只根据本回合已公开、重复发生的共同移动，识别这种重复并放弃可选随行；不读取私有续算、牌堆或未来骰子，也不取消已确认技能。新回合重新判断，正常有进展的随行照常选择。

首轮约30MB的原始病态存档也已用修复后策略原样续跑：保持历史、待处理栈与已生成随机结果，56次合法动作后完成四场，403个待处理项降到0；约6.4秒内发布318条新公开事件，完成16次可选技能放弃。修复前的首次续算曾耗尽测试进程内存，此后补齐旧随行记录离开120条窗口时的同行者公开动作识别，最终续算通过；新回归同时验证在首次重复及时退出。

## 已执行验证

- 类型检查、两种生产构建、Worker部署预演和233项单元／集成检查通过。包括完整事件分页、鉴权、私密续算不泄露、跨版本与React合批、跨场保留、双骰点击与存档、AI响应及预测显示时机。
- 高频重复快照下逐项对照权威事件ID：默认与4×减少动效均完整显示骰子、两段移动、技能和后退，前序未播完时不插入待选面板。默认两次技能实测1805.8／1803.6ms，加速减动效实测1502.4／1506.1ms，0页面脚本错误。
- 真实Node传输单次超过120条日志，初始骰子／技能／移动全部位于短窗口之外，实际经多页补齐后依次播放，未直接跳至结果。提前进入下一场仍等待旧骰子、移动和冲线完成。
- 双真人决斗、真人对AI决斗均通过：每个真人只操作自己的骰子，AI不需要客人页面点击；成对骰后才出现胜负技能与移动。默认双骰实测1501.1ms揭晓、1500.1ms静止阅读、3001.2ms整段；4×减少动效直接定点但保留1.5秒读数。
- 手机冠军预测常驻、多个预测者、模仿猫及结束清理通过。桌面完整链跟拍回位、总览、手动拖动暂停、跟拍开关与手机自动回合开始选择两项回归通过（52.3秒）。
- AI重复随行修复后，额外用虚拟时钟验证20个固定种子的4人完整对局：80场、6544次合法动作，单局最多467次动作，均完整结束且无操作超时。此项是引擎／策略检查，不代替真实浏览器完整四场。
- 本地Worker中的真实三AI四场重跑通过：277,324ms，231次AI自主推进、55次AI技能选择、0次动画跳过点击、0页面脚本错误，最终等待棋盘idle与成绩面板可见。观察404个严格递增的片段事件ID和525次阶段变化，包含骰子、技能、移动、传送、冲线、绊倒、得分、起身、交换和淘汰。本整局未保存完整权威日志作逐项差集；严格逐项比对来自上述高频快照与待选专项，二者不混称。另用第四场短局确认权威已经finished时仍完整播放dice→move→finish→idle后才显示总成绩。
