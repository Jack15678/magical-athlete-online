# Second Wind 本地接入验收

验收日期：2026-10-21。实现通过独立开发分支提交审阅；本文记录本地验证结果，本轮未部署或更新线上网站。

已经接入新增 36 个角色的数据、技能入口和独立 Blender 模型，提供原作 36 / Second Wind 36 / 混合 72 的建房选项，以及完整牌池选四张的练习入口。**目前不能标记“完整支持72个角色”**：续作官方完整规则书、部分复制与结束边界、跨回合循环仍待核实。

## 运行

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm dev:browser
```

浏览器房主模式访问 `http://127.0.0.1:8787`，沿用原有 Worker 中继和原浏览器权威存档。此模式的随机与规则仍由唯一浏览器计算房主统一处理；它不是独立服务器计算。备用 Node 模式通过 `pnpm start` 运行，服务器统一处理相同规则。聊天、身份、消息顺序和昵称分配在两种路径均由房间服务处理。

角色卡使用同一份规则数据展示简述和展开详情，提供版本筛选、中英文搜索、来源与核验状态。能力面板展示当前实际能力、复制、额外能力、禁用原因、次数及形态、坐骑；动作与回合外选择归当前控制者。场上实例、角色定义、初始身份与当前控制者分别记录。

新增头像均为逐角色绘制的二维卡通 SVG，使用旧头像相同的扁平填色、粗黑描边和圆框尺寸，不再以 3D 模型渲染图充当头像。编号与状态标记保留在外层；手机浮动头像与小地图检查裁切及边界。骑乘者按实际鞍座高度缩放、落座；纸白和深色材质沿用原作的表面参数。

原作双人固定行动顺序、粘液怪的局部自定义范围和 7–8 人扩展继续保留。Re-Runner 的额外实例跟随当前控制者的行动组，不限制每个玩家只有一或两名选手。控制、变身、坐骑事件携带当时的状态快照，播放连续事件不会提前套用最后状态。

房间规则版本决定实际运行的引擎；更新前的原作存档继续使用保留的旧引擎，重新开局才切换。新旧角色混用现有 Mild / Wild / Mild / Wild 赛程属于明确配置；官方合盒 Mild Mile → Wild Wilds → Twisty Twirl → Whirly World 尚未开放，因为两条新赛道的布局与专属效果未核实。

## 聊天和昵称

最近 100 条消息在大厅、四场比赛和重连之间保留，纯文本显示。消息编号、时间、历史昵称和稳定发送者 ID 由房间服务确定；重复请求、频率、长度和成员权限均检查。聊天使用独立序列，不推进游戏版本和待选技能。

玩家、AI、观战者共用昵称命名空间，统一去空格、NFKC 规范化及大小写比较，原子分配最小可用数字后缀。旧房间中已有的重名会修复，身份、积分及手牌不变。真人每完整四场可成功手动改名一次，刷新、重连不重置；自动后缀和失败提交不扣次数，新局恢复。

**正式解散或房主连续离线 30 分钟自动关闭时，聊天记录和发送回执随房间删除。** 已验证服务重建后不能读取旧消息；其他房间的数据保留。临时退出、刷新、断线和原房间再来一局不会提前清空历史。

## 已执行验证

- 全量单元、规则、存档、权限、真实 Socket.IO 和 Worker 中继测试：466/466 通过；包含每个新增角色的行为用例、72 个矢量头像与导出文件一致性，以及聊天/改名提交后恰好过期的真实连接回归。
- Node 与 Worker 类型检查及两种构建通过。Three.js 分包大于 500 kB 的既有构建提示不阻塞产物生成。
- 真实房间中继浏览器验收：续作牌池、混合牌池分别完成三名独立玩家的四场对局，另含观战者；72 张练习筛选与跨筛选保留选择也通过。
- 联机中检查聊天实时同步、观战发送、纯文本、未读、阅读旧消息时不抢滚动、失败改名不扣次数、改名历史、刷新与房主恢复、跨场保存及新局次数重置。手机视口检查展开聊天没有覆盖技能按钮、聊天按键不会执行游戏操作。
- 38 份 GLB 真实解码、36 张模型预览、五个动画、体积和原点、材质及预算、源文件 SHA-256 和闭合网格检查：41/41 通过。全部模型约 1.50 MiB，参赛模型按需请求。
- 36 张二维卡通头像在浏览器中逐张检查 91 px 和 28 px 圆框显示；界面使用矢量路径，保留外层编号及状态标记，没有方形图片覆盖圆框。见[新旧画风对照图](qa/second-wind/cartoon-avatar-contact-sheet.png)。
- 180 局公共视图 AI 压力检查：169 局完成四场，6 局在六骰没有重复点数时明确保存规则暂停，5 局达到检查操作上限且仍有合法动作；无异常、内存耗尽或缺失动作。不能把它写成 180 局全部完成。原先混合 8 人复制连锁的内存耗尽已有独立重现与回归用例。

## 仍未完成的核验

1. Ludopedia 入口与发行方 Discord 线索没有取得可验证版本的续作完整规则。36 张新卡目前按玩家卡文转录接入，全部标注待官方复核；没有将站主 Interactions 当成官方规则。
2. Mr. Dice Guy 六骰各不相同时没有合法重复点数，目前保留队列暂停，不自行决定跳过或重掷。Show-Off、Doppelgängster、复制叠加、坐骑离场、取消比赛奖励及跨回合强制循环等逐项列在规则资料中。
3. 只有单幅参考的侧背由项目补全；Bite Mark 巨口形态属于明确记录的设计推断。五个片段为父级动作，非关节骨骼动画；局内摔倒继续使用既有支撑计算，避免重复倾倒。
4. 手机检查使用浏览器视口及键盘事件，不是物理手机 GPU 或真实软键盘实机测试。
